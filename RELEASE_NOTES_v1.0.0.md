HideDryTimeMod 1.0.0

What this mod does
- Changes drying time for hides, pelts, gut, and saplings.
- Lets you pick Vanilla, fixed presets, or custom in-game hours.

Highlights
- Presets: Vanilla, 6h, 12h, 24h, 48h, 72h, 168h
- Custom range: 1-168 hours
- English and Russian localization

Install
- Put HideDryTimeMod.dll into Mods folder.
- Launch game and configure via ModSettings.

Compatibility
- The Long Dark Il2Cpp
- MelonLoader
- ModSettings 2.2.5
